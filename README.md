# CodeAlpha - Basic Network Sniffer

A Python network packet sniffer built using **Scapy** for real-time network traffic analysis. Developed as part of the **CodeAlpha Cybersecurity Internship Program**.

## Features
- Captures IPv4 and ARP packets in real-time.
- Parses TCP, UDP, ICMP, and ARP traffic.
- Displays source/destination IP addresses, port numbers, and packet sizes.
- Extracts payload data.

## Prerequisites
- Python 3.x
- Scapy (`pip install scapy`)
- Administrative / Root privileges

## Usage
Run with Administrator / Root privileges:
```cmd
python network_sniffer.py
